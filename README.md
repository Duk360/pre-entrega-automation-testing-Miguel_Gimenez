# Proyecto Pre-Entrega: Automation Testing con Selenium y Pytest

## Propósito del proyecto
Este proyecto aplica pruebas de automatización sobre el sitio web [SauceDemo](https://www.saucedemo.com/) utilizando Python, Selenium WebDriver y Pytest. Permite validar los flujos principales de inicio de sesión, verificación del catálogo de productos e interacción con el carrito de compras.

## Tecnologías utilizadas
* **Python 3** (Lenguaje de programación)
* **Selenium WebDriver** (Herramienta para automatización de interfaz gráfica web)
* **Pytest** (Framework para ejecución de casos de prueba y aserciones)
* **pytest-html** (Plugin para la generación de reportes ejecutivos en formato HTML)
* **Git y GitHub** (Control de versiones y alojamiento de código)

2. Asegurarse de tener un entorno virtual activo.
